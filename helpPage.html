Using the Launcher

Getting Started

The Among Us Launcher handles downloading, updating, and launching the game. No Steam, no itch.io account required — just download and play.

What it does

On startup the launcher checks for the latest game version, updates automatically, and lets you switch versions if a mod requires an older build. Discord rich presence runs while the game is open.

NoteWindows Defender may flag the launcher as suspicious. This is a false positive — it has no publisher signature because it is not commercially distributed. Full source is on GitHub.

Requirements

  • Windows 10 or later (64-bit)
  • Visual C++ Redistributables — see
  • Internet connection for the first download

First launch

Download AmongUsLauncher.exe from the home page.
Run the file. If Windows SmartScreen appears, click "More info" then "Run anyway."
Wait for the download. The launcher fetches the latest Among Us build automatically. Takes about a minute depending on your connection.
Click Launch. The game starts. The launcher stays in your system tray while you play.
TipPin the launcher to your taskbar for faster access — right-click the exe and choose "Pin to taskbar."
Help

Troubleshooting

Run through this before asking in Discord. Most problems are covered here and fix in under two minutes.

Launcher won't open

  • Install both the x64 and x86 Visual C++ Redistributables. See .
  • Confirm you're on Windows 10 or later. Windows 7/8 are not supported.
  • Right-click the exe and choose "Run as administrator."
  • Check your antivirus isn't quarantining the file. Add an exception for the launcher folder.

Game won't launch from the launcher

  • Let the download finish completely. A partial install won't run.
  • Delete the Among Us folder inside the launcher directory and restart to re-download fresh.
  • Temporarily disable your antivirus. Some AV software kills Among Us processes on spawn.
WarningDo not move the launcher exe after the game has downloaded. The launcher stores the game relative to its own location — moving the exe breaks the path.

Launcher says "Update failed"

  • Check your internet connection.
  • GitHub's release servers occasionally have brief outages. Wait a few minutes and retry.
  • If the problem persists more than an hour, report it in Discord with a screenshot.

itch.io ownership error

Use the Itch Login Fixer on the home page under "Don't need the launcher?" — follow the instructions there.

Black screen on launch

  • Update your graphics drivers.
  • Try windowed mode: hold Alt while launching.
  • If you have multiple monitors, move the window to your primary display.

Discord Rich Presence not showing

  • Open Discord before launching the game.
  • In Discord settings, enable "Display current activity as a status message."
  • Restart both the game and Discord.

Still stuck?

Search this page — your issue is probably answered above.
Check the #support channel for recent similar reports.
Post in #support with your Windows version, exactly what happens, and a screenshot if possible.

Required Software

The launcher requires the Microsoft Visual C++ Redistributables. Install both — x64 and x86 — even on a 64-bit system.

Download links

  • Visual C++ x64 Redistributable
  • Visual C++ x86 Redistributable

Install steps

Download both files from the links above.
Run the x64 installer first. Accept and complete it.
Run the x86 installer. Accept and complete it.
Restart your PC. Then try launching the launcher again.
TipIf you already have these installed and the launcher still crashes, try repairing the installation — run the installer again and choose "Repair" instead of "Install."

Build Your Own Tool

Want to build your own launcher, updater, or game tool? Here's exactly how the Among Us Launcher works under the hood so you can do the same or better.

Core concepts

  • GitHub Releases as a CDN — game files and launcher updates are stored as release assets on GitHub. The launcher checks the releases API at startup, compares the latest tag against the installed version, and downloads the zip if they differ. No custom server needed.
  • Version pinning — the installed version tag is written to a local file alongside the game directory. On next launch, the launcher reads this file and skips the update if the tag matches.
  • Extraction in place — the downloaded app.zip is extracted directly into the game folder, overwriting only changed files. The zip structure mirrors the game directory tree.

The update loop

Fetch https://api.github.com/repos/<owner>/<repo>/releases/latest
Compare tag_name from the response against the locally stored version string.
If different: find the asset named app.zip in assets[], download it via browser_download_url.
Extract the zip into the game directory, write the new tag to the version file.
Launch the game executable.

itch.io auth

The itch file in %USERPROFILE%\AppData\LocalLow\Innersloth\Among Us\ holds the OAuth token that Among Us reads to verify itch.io ownership. Writing a valid token there bypasses the ownership check — this is what the Itch Login Fixer does via itch.io's implicit OAuth flow.

Discord Rich Presence

The launcher connects to the local Discord client over named pipe \\.\pipe\discord-ipc-0 using the Discord Game SDK RPC protocol. It sends activity payloads with the current game state — map name, lobby size, role. The client_id in the source maps to the registered Discord application.

Tip If you're building a similar tool for a different game, the GitHub Releases pattern works for any game distributed as a zip. Swap the repo URL and the executable name — everything else stays the same.

Website Stack

The site is intentionally zero-framework. No React, no bundler, no build step. Just HTML, CSS, and vanilla JS deployed on Vercel.

Why no framework

The pages are mostly static with a few dynamic fetches. A framework would add hundreds of kilobytes of JS for no meaningful gain. The current site loads under 50KB of actual code (not counting fonts and images).

Stack breakdown

  • HTML/CSS/JS — no preprocessors, no transpilation, no build
  • Share Tech Mono (Google Fonts) — the only external font, loaded once
  • Plyr (cdnjs) — video player used for the Itch Login Fixer tutorial
  • marked.js (cdnjs) — markdown rendering on post.html
  • Vercel — deployment, serverless functions live in /api/
  • GitHub Releases API — launcher version and game zip discovery
  • Custom messages API — https://amongus-launcher.vercel.app/api/messages proxies Discord messages for the trust wall

Canvas background

The star field and beans are rendered on a <canvas> element fixed behind all content. Stars use pre-baked sprite canvases (one per radius class) to avoid per-frame gradient recalculation. Beans use pixel-level colour recolouring from a single bean.png source image — each colour variant is stamped once into a cached canvas on load.

Design tokens

  • Background — #090909
  • Accent — #c8151b (red only, no gradients, no secondary accent)
  • Text — #f0f0f2
  • Font — Share Tech Mono throughout, zero Inter, zero Rubik
  • Spacing principle — absolute positioning over flex grids where possible, intentional asymmetry

Adding a page

Copy post.html as a base. It has the nav, canvas, hub drawer, and bean toggle already wired up. Swap the content and update the <title> and the active class on the right nav item.

Tip The bean state persists via localStorage under the key 'beans'. Any new page you add should read it with localStorage.getItem('beans') !== 'off' and set window.__beansEnabled before the canvas loop starts.
