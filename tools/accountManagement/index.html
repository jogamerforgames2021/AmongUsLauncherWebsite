Fix the itch.io login error

If Among Us won't log in through itch.io, this writes a small verification file to your game's local data folder so it stops asking. You'll need to own Among Us on itch.io for it to work.

This is a workaround, not an official patch, so it can stop working after an itch.io or Among Us update. v1.4 · Jul 2026

Apply the fix
Downloads a file named itch with your token already inside it. You just move it into place.
  1. Press + R to open the Run dialog.
  2. Paste in %localappdata%low\Innersloth\Among Us and press Enter.
  3. Move the downloaded itch file into that folder.
  4. If a file named itchverify already exists there, delete it.
Use this if your browser blocks downloading files with no extension.
  1. Press + R to open the Run dialog.
  2. Paste in %localappdata%low\Innersloth\Among Us and press Enter.
  3. Right-click an empty space, choose New → Text Document.
  4. Rename it to itch and delete the .txt extension so nothing is left after the name.
  5. Open it, paste in the copied above, save, and delete any itchverify file.
